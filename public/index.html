Sobre o projeto

Este site nasceu de uma atividade da disciplina de Introdução ao Desenvolvimento Web: construir, só com HTML, o formulário de inscrição de um evento acadêmico. A partir daí, o projeto evoluiu em etapas até virar um sistema completo, que recebe, valida e guarda as inscrições em um banco de dados e está publicado na internet.

Como ele evoluiu

  1. HTML puro — o formulário da atividade: campos certos para cada dado e rótulos (label) ligados a cada campo.
  2. CSS e acessibilidade — visual, versão para celular, tema escuro e grupos de opções anunciados corretamente por leitores de tela.
  3. Servidor Node.js — o formulário passa a enviar os dados de verdade (POST).
  4. Arquivo JSON — primeira forma de guardar os dados, para entender o fluxo e sentir os limites de viver sem banco.
  5. Banco SQLite e SQL — tabelas relacionadas, chaves, restrições, transações e relatórios.
  6. Publicação em VPS — Nginx, HTTPS, PM2, backups, área administrativa protegida e LGPD.

Quando você envia o formulário, o navegador faz uma requisição POST protegida por HTTPS. O Nginx recebe e repassa ao servidor Node.js, que valida tudo de novo (nunca confia só no navegador) e grava a inscrição numa transação: ou a inscrição e suas atividades são salvas juntas, ou nada é salvo.

Boas práticas aplicadas

Segurança

  • Consultas SQL parametrizadas (contra SQL injection)
  • Dados exibidos como texto (contra XSS)
  • Limite de envios por IP contra robôs
  • Cabeçalhos de segurança e HTTPS

Dados

  • Validação no navegador e no servidor
  • Restrições no próprio banco (UNIQUE, CHECK, chaves estrangeiras)
  • Transações: nada fica salvo pela metade
  • Backups diários automáticos

Pessoas

  • Acessível por teclado e leitor de tela
  • Funciona bem no celular
  • Consentimento e política de privacidade (LGPD)
  • Lista de inscritos só para administradores
